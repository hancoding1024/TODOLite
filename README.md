# TodoLite

一个极简的 Windows 桌面待办工具：上面写，下面做——收件箱随手记，TODO 列表专心做。

没有日期、提醒、优先级、标签、搜索、账号、云同步，整个程序里没有一个时间字段。

## 特点

- 单个 exe，零第三方依赖，不写注册表，删掉即卸载干净
- 单实例运行，关窗即退出，没有托盘、没有后台常驻
- 界面与数据里都没有任何时间、日期字段

## 安装

**方式一：直接下载（推荐）**

到 [Releases](../../releases) 下载，双击即可运行。

**方式二：从源码构建**

```bat
git clone <仓库地址>
cd <仓库名>\src
build.bat
```

产物输出到仓库根目录的 `TodoLite.exe`。编译前请先退出正在运行的 TodoLite。

> 需要 Windows 10 / Windows 11（系统自带 .NET Framework 4.8），不需要另装任何依赖。

## 使用

1. 在上方收件箱写下要做的事，按 `Enter` 记入 TODO 列表；要换行按 `Shift+Enter`。
2. 写多行也只会生成**一条** TODO，中间的换行会合并成一个空格。
3. 没提交的文字会自动保存，关掉程序再打开还在。
4. 做事时只看下面的 TODO：点勾选框标记完成（划线置灰、位置不变），再点一次取消。
5. 双击文字或按 `F2` 可以改名，`Delete` 或行尾 `×` 删除。
6. 按住某一行上下拖动即可调整顺序。
7. 右键 TODO 列表 →「清除已完成」，一次性清掉做完的。

### 快捷键

| 按键                | 作用                   |
| ------------------- | ---------------------- |
| `Enter`             | 记入 TODO              |
| `Shift+Enter`       | 换行                   |
| `F2`                | 编辑选中的事项         |
| `Delete`            | 删除选中的事项         |
| `Esc`               | 取消编辑               |
| `Ctrl+1` / `Ctrl+2` | 跳到收件箱 / TODO 列表 |

## 数据

所有数据保存在 exe 同目录的 `todo-data.json`，纯本地、不上传。若该目录不可写（例如放进 `C:\Program Files`），会自动改用 `%APPDATA%\TodoLite\`。

搬走程序时把这个文件一起带上；删掉它就等于清空所有事项。
